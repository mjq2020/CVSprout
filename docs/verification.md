## 适用范围

GPU 实测环境为 Linux x86-64、RTX 4090、PyTorch 2.6.0+cu124。不能据此承诺所有 GPU、驱动和 CUDA 组合可用。合成数据只验证训练和部署链路，不评价业务精度。

本环境不是 Windows，PowerShell / WSL2 的首次安装仍需 Windows 实机验收。RKNN / TensorRT 保留接口回归；未在本次新增环境安装专用 SDK 或验证板端部署。

预构建镜像的发布工作流已准备，但没有向 GitHub/GHCR 发布。独立异地 worker 注册与跨机器数据传输尚未实现；远程使用方式为在 GPU 服务器部署完整栈。
