# CVSprout 工业标注平台

按模块了解功能、角色权限、实现入口与当前边界，请先阅读[模块与功能说明](modules-and-features.md)；本手册提供具体操作流程。

CVSprout 面向多人协作的视觉数据工作流：导入 → AI 批量标注 → 人工校正与审核 → 冻结数据版本 → 训练 → 模型转换与导出。支持目标检测、实例分割、单标签图片分类和对象关键点；服务与队列运行在单机上，成员使用各自账号通过浏览器协作。

## 当前能力

- 项目、标签和标签属性 JSON Schema 管理；管理员可归档、恢复或输入项目名称确认永久删除
- JPG、PNG、WEBP、BMP 多文件及 ZIP 数据集上传，项目内按 SHA-256 去重
- 管理员可单张或批量删除导入图片，预览标注数量，逐张检查编辑占用与版本冲突；历史数据版本和训练记录保留
- 按 64–1024px 尺寸生成并长期缓存 WEBP 缩略图，数据网格无需下载原图
- AI 优先的矩形框、多边形、整图分类和对象关键点标注；人工可修改类别、轮廓、关键点位置与可见性
- 图片编辑租约、标注对象版本和图片 revision 乐观并发控制
- 按数量创建标注任务块、独占领取、我的任务、审核退回与管理员转交；负责人绑定账号，关闭浏览器不丢失分配
- 检测、分割和关键点图片可明确“确认无目标”，空标注图片也能提交审核并作为负样本导出
- 草稿、待审核、通过、退回和重新打开的审核流程；批量提交/通过/退回、逐项冲突反馈与连续审核
- 标注软删除、来源/模型记录、审核事件和项目审计日志
- 运行时模型注册中心：新增、编辑、停用、删除自定义服务和连接检查
- 开箱即用的本地全自动标注：Grounding DINO Tiny 开放词汇目标检测
- 开箱即用的本地全自动标注：SAM 3 文本概念实例分割
- 开箱即用的本地半自动标注：SAM 2.1 Hiera Tiny 正点、负点、粗框和粗多边形提示
- 可选远程模型：Qwen3.5 或自定义推理服务
- SQLite 持久任务队列：原子领取、worker 租约、推理续租、取消、重试和失联恢复
- COCO、YOLO、完整 JSON 导出；分类使用 train/val/test 类别目录；导出包包含 SHA-256/revision 清单
- 不可变数据集版本：复制媒体、标签、标注和资产元数据，记录内容哈希，并按种子确定性划分 train/valid/test；滑动条联动调整比例、预计张数、冻结缩略图和分组图片浏览
- 版本生成向导：选择数据、划分比例、配置增强、预览确认；16 种训练集增强，支持按倍数或新增张数设置扩增量，中文说明、参数和标注同步预览，冻结实际增强图片与来源记录
- 左侧集中显示项目上下文、工作流、服务状态和账号，可收起并在手机上切换为抽屉；浅色、深色和跟随系统主题；训练与 AI 标注页用顶部子标签切换内容
- 项目分析与质量检查：工作流、审核、类别、来源、形状分布，以及缺失文件、空标注、低置信度等问题
- 生产化训练控制面：多模型目录、检测/分割/分类/关键点显式任务、数据兼容检查、完整超参数白名单和配置哈希
- 持久训练日志、逐 epoch 指标；训练/验证 loss 曲线、分量切换、逐轮数值、任务对应的验证表现；取消/重试谱系、checkpoint 恢复、执行代次 fencing 和 `best.pt` 校验下载
- CPU/GPU 资源快照与单机 GPU 独占租约；多个 pipeline worker 不会同时占用同一张训练卡
- ONNX、TorchScript、RKNN 和 TensorRT 转换；按格式配置、环境检查、取消/重试、持久日志、产物校验及部署说明下载
- 登录页自行申请注册，管理员审批并分配管理员/标注员/审核员角色；拒绝反馈与重新申请、首次改密、个人改密、账号/IP 登录限流、设备会话撤销和安全审计；保留管理员 Bearer Token 兼容入口
- 鼠标位置锚定缩放、手形/空格/中键平移、真实 100% 显示及一键适配；查看图片不需要编辑权限

演示模型默认不会注册。仅自动化测试显式启用它，生产数据不会依赖伪造的中心框结果。

## 启动

安装与首次设置见 [快速入门](../README.md) 和 [环境检查](installation.md)。

更新代码后需要重启后端服务并刷新浏览器。若项目入口提示“后端任务块接口不可用”或旧版本兼容提示，请按 [升级后页面提示接口不可用](../README.md#升级后页面提示接口不可用) 重新构建、启动 Docker 服务，或停止并重启原 Python 进程；单独执行 `git pull` 不会更新已运行进程中的接口。旧接口返回 404 不表示项目被删除。已启用任务块的项目必须使用完整的新版本接口，避免绕过任务归属。

## 界面与主题

桌面左侧导航集中显示当前项目名称、任务类型、图片数量和工作流程。页面内容直接从顶部开始，避免重复显示项目信息。左侧底部可查看标注服务状态、设置主题，以及打开账号菜单进入“账号与安全”或退出登录。

点击左下角“收起导航”可切换为图标栏；收起后仍能点击主题和头像图标打开设置。普通页面和标注页面分别记住导航的收起状态。手机点击顶部菜单按钮打开导航，选择功能后自动关闭；也可点击关闭按钮、遮罩或按 Esc 退出。

点击左侧底部“主题”，在“外观主题”中选择：

| 选项 | 效果 |
|---|---|
| 浅色 | 始终使用浅色界面 |
| 深色 | 始终使用深色界面 |
| 跟随系统（默认） | 随操作系统或浏览器的明暗偏好自动变化 |

切换立即生效，不刷新页面，保留当前表单和未保存标注。偏好保存在当前浏览器，同一地址的其他标签页会同步；不随账号同步到其他设备。清除站点存储后恢复跟随系统。主题只调整界面，原始图片、模型输入和标注类别颜色不变。

切换项目模块时，当前内容保留到新页面就绪；加载过程中原内容暂时不可操作，仍可用左侧导航切换目的地。较慢的请求会显示加载提示；失败时可点击“重新加载”。页面、标签页和弹窗使用短暂过渡，系统开启“减少动态效果”时自动关闭这些动效，标注画布不参与入场动画。

数据页搜索、状态筛选和“再显示”在当前页面更新，保留搜索焦点、中文输入过程、已有图片及滚动位置；筛选后内容变短时，滚动位置会随列表长度收缩。没有匹配结果时可直接清除筛选。训练后台同步在内容未变化时保留原页面，只更新同步时间或连接提示；手动刷新、训练进度、失败信息和转换结果仍正常显示。

## 删除项目

管理员在项目列表的项目卡片上点击“删除”；普通列表和“已归档”列表都提供入口。确认窗口会列出删除范围，必须完整输入窗口显示的项目名称（包括大小写及空格），才可点击“永久删除”。取消或输入不匹配时不会删除，接口也会重新校验管理员权限与项目名称。

永久删除会移除该项目的图片、标注、标签、任务块、AI 任务记录、数据版本、训练及转换记录和产物，无法在页面中恢复。需要保留的内容请先导出或备份；共享基础模型、模型服务及其他项目不受影响，审计记录保留。若只想暂时收起项目，使用“归档”即可。

项目仍有排队或运行中的 AI 标注、训练、转换，或有人持有有效图片编辑租约时，删除会被阻止。先结束或取消任务、退出图片编辑后再试。删除失败会在确认窗口显示原因，保留已输入的内容。

若提示“项目已删除，部分文件待管理员清理”，项目数据已从系统移除，但部分文件因存储权限等问题尚未清理。管理员应检查服务日志及删除审计中的清理记录，不要重复提交删除请求。

## 画布操作

将鼠标放在图片区域，滚轮即可围绕鼠标所在位置放大或缩小；触摸板 Ctrl+滚动同样可用。选择手形工具后左键拖动，或临时按住空格拖动、使用中键拖动。查看按钮提供放大、缩小、适配和真实 100% 比例；放大后可拖到图片四角。只读图片也可缩放、平移，平移不会产生标注。选中标注后拖动框、轮廓顶点或关键点进行校正，底部会显示保存状态。

## 从其他设备访问

查询服务主机的局域网 IP：

```bash
hostname -I
```

假设地址是 `192.168.1.50`，同一局域网设备访问 `http://192.168.1.50:8000`。连接失败时确认主机防火墙或云安全组允许 TCP 8000。

多人协作默认使用 `MDP_AUTH_MODE=accounts`。首次运行先用上面的 CLI 创建管理员，密码由终端交互读取（至少 12 个字符），不会写入命令行参数。管理员登录后在“用户管理”搜索和管理成员，创建标注员、审核员，分配角色、停用账号或重置密码。管理员创建及重置密码的账号必须先修改初始密码，服务端也会限制其访问业务接口；既有账号升级后不会被强制改密。角色变更、停用与密码重置立即撤销该用户的会话和编辑租约；只改显示名称不退出登录。至少保留一位启用的管理员。

用户也可以在登录页选择“申请注册”，填写账号、显示名称、至少 12 个字符的密码，以及可选的申请说明。申请进入“用户管理 → 注册申请”，管理员核对后选择角色批准，或填写原因拒绝；列表支持搜索、状态筛选和分页。审批前不会创建可登录账号，也不能访问任何项目；审批通过后，使用注册时设置的密码即可登录。申请人可在登录页输入正确账号密码查看待审批状态或拒绝原因，按反馈修改显示名称和说明后，使用原申请密码重新提交。重复提交待审批申请不会覆盖管理员正在审阅的内容；并发或过期审批会要求刷新。注册与登录均有限流，密码仅以哈希保存，审批过程留有审计记录。

登录与注册共用一致的表单样式，支持显示/隐藏密码、字段级错误提示、键盘切换标签和窄屏滚动；忘记密码请联系管理员。

左侧底部账号菜单中的“账号与安全”提供个人资料、验证旧密码后改密、登录设备管理和最近安全记录。个人改密会撤销所有旧会话，并为当前浏览器签发新会话。管理员可以查看成员设备与安全记录、撤销全部登录、清除账号登录失败限制。密码和完整会话令牌不会返回到成员列表或日志。

| 能力 | 管理员 | 标注员 | 审核员 |
|---|---|---|---|
| 浏览、导入、AI 标注、领取任务、校正本人任务、提交审核、下载数据 | ✓ | ✓ | ✓ |
| 审核通过/驳回、重新打开已通过图片 | ✓ | — | ✓ |
| 冻结版本、创建/取消/重试训练与转换 | ✓ | — | ✓ |
| 创建项目、管理标签、模型服务、账号 | ✓ | — | — |
| 创建任务块、转交任务块、重新打开已完成任务块 | ✓ | — | — |

当前采用团队共享项目空间，角色是全局角色，尚无项目级成员隔离。图片编辑锁按登录会话区分，不同成员可以同时处理不同图片；同图冲突返回明确提示。会话有效期 8 小时，退出即失效；登录限制同时按账号与来源 IP 计算，避免仅换账号绕过限制。停用账号不会删除标注或审核记录。

启用任务块后，人工标注与提交审核还要满足任务块归属：管理员也需要领取或转交到自己名下才能修改图片。审核员仍可审核其他成员提交的图片。图片编辑页面另有独立令牌，防止同一登录会话的多个标签页互相覆盖或释放编辑锁；长期负责人绑定账号，不随编辑锁到期而改变。未启用任务块的旧项目维持原有工作流。

跨网络部署时，在服务前配置 Nginx/Caddy HTTPS，并设置：

```dotenv
MDP_AUTH_MODE=accounts
MDP_COOKIE_SECURE=true
# 代理若改写 Host，请填写浏览器实际访问的来源，不带路径。
MDP_PUBLIC_ORIGIN=https://vision.example.com
```

通过 Cookie 登录的写请求会校验 Origin/Referer；没有来源头的自动化客户端须显式发送 `X-MDP-Client: browser`，或使用管理员 Bearer 认证。应用不开放跨域 CORS。只向可信的反向代理开放代理头信任，避免伪造来源 IP。普通内网 HTTP 测试保持 `MDP_COOKIE_SECURE=false`；正式跨网络部署应使用 HTTPS。安全措施参考 [OWASP 会话管理](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html)与 [CSRF 防护](https://cheatsheetseries.owasp.org/cheatsheets/Cross-Site_Request_Forgery_Prevention_Cheat_Sheet.html)。

旧部署可继续使用 `MDP_AUTH_MODE=token` 和至少 32 字符的 `MDP_BOOTSTRAP_API_KEY`。此令牌始终代表管理员，不用于区分协作者。`disabled` 模式仅适用于本地开发；升级时若已有 `.env` 显式设为 `disabled`，需要改为 `accounts`。`/api/health` 保持匿名可读，注册与登录接口可匿名访问，其余业务 API 均要求认证。

## 任务块协作

任务块把同一项目中的图片分给不同成员，图片文件不会被复制，已有标注和数据版本也不会被清除。任务块只决定谁负责标注，与训练集、验证集、测试集的划分无关。所有成员仍可查看项目数据；任务归属限制的是修改，不是数据可见性。

推荐先导入图片，完成可选的 AI 预标注，再创建任务块并开始人工领取。也可以先启动 AI 任务，在任务运行期间分块：涉及排队或运行中 AI 任务的块显示“AI 处理中”，不能领取；AI 结束后才能交给人工。已创建但尚未领取的块也能启动 AI，但系统没有单独的“等待管理员开放”状态，计划预标注时应先启动 AI，再通知成员领取。块一旦被领取，或已有人工标注，后续整项目 AI 批量标注会跳过这些图片，显式选择这些图片运行批量 AI 则会拒绝。负责人仍可使用编辑器中的单图 AI 辅助；辅助结果保存为草稿，由负责人检查后提交审核。

使用流程：

1. 管理员进入左侧“标注任务块”，点击“创建任务块”，默认每块 **50 张**，可设为 **1–500 张**。只对尚未分块且未提交审核的图片创建新块；已有块的图片范围保持固定，新导入的图片需要再次创建任务块。
2. 成员使用独立账号登录，领取一个可用块。两人同时领取同一块只有一人能成功；“领取下一块”会选择不同的可用块。每个成员在同一项目最多主动领取一个未提交或已退回的块，先处理完当前工作再领取下一块。
3. 使用“我的任务”筛选，点击块内的“继续标注”，图片浏览和连续标注限定在这个块内。页面还可筛选“待领取”“待审核”“需修改”“已完成”或“全部”。其他成员打开图片时只能查看；后端同样检查归属，不能通过直接调用保存接口绕过限制。
4. 完成标注后逐图或批量提交审核。保存草稿不等于提交；没有目标的图片应明确选择“确认无目标”，然后提交审核。分类项目仍需选择一个类别。添加标注对象会清除此前的无目标确认。
5. 整个块提交后，成员可以领取下一块。审核员逐图或批量通过、退回；退回原因可选，留空也可以提交，填写后便于负责人了解修改要求。退回图片仍由原负责人修改，已通过的图片保持只读。有退回任务时优先处理退回任务。
6. 块内全部图片审核通过后，块自动标记“已完成”。完成表示结束工作占用，负责人和审计历史仍保留，块不会再次进入待领取池。

| 块状态 | 含义 | 后续操作 |
|---|---|---|
| AI 处理中 | 块中图片仍由 AI 处理 | 等待 AI 结束后领取 |
| 待领取 | 未分配负责人，可以开始人工处理 | 领取或由管理员分配 |
| 标注中 | 已分配负责人，部分图片尚未提交 | 负责人继续标注并提交 |
| 待审核 | 所有图片已提交或通过 | 审核员处理，负责人可领取下一块 |
| 需修改 | 部分图片需要修正 | 原负责人查看原因并重新提交 |
| 已完成 | 所有图片审核通过 | 可用于冻结数据版本；返工需管理员明确重新打开 |

主动交回和管理员转交都会保留已保存的标注。转交会清除旧编辑锁，并使旧页面的保存版本失效；原负责人需要刷新，不能继续写入已转交图片。交回的块可以被其他成员领取；如果块内图片已经全部提交，它仍保持待审核，避免重复分配。接手人应先检查已有结果。长期未处理的任务由管理员联系负责人后转交；第一版不自动回收任务，短暂断网、退出登录或关掉浏览器均不会丢失负责人。

已完成的块不能直接再次领取或转交。需要返工时，由管理员填写原因重新打开整个块：保留标注，块内图片回到草稿，再按需要转交和审核。不能通过单张图片的“重新打开”绕过已完成块的保护。已冻结的数据版本始终保持原样。

首次在旧项目启用任务块前，先关闭编辑中的图片。创建块不会把已经提交或通过的历史图片再次分配，也不会丢弃现有人工标注。启用后，新图片在分块、领取前不能直接标注；已有待审核图片仍可正常审核。需要对历史已通过图片返工时，应先按原审核流程重新打开，再为未分配图片创建任务块。没有创建任何块的项目继续支持原来的直接标注方式。

自动化接口以 `/api/projects/{project_id}/work-blocks` 为基础路径，写操作沿用现有登录与 CSRF 规则：

| 方法与路径 | 用途与参数 |
|---|---|
| `GET` 基础路径 | 返回块列表、是否启用、尚未分块图片数 |
| `POST` 基础路径 | 管理员创建块：`{"block_size":50}` |
| `POST /claim` | 领取下一块：`{}`；指定块：`{"block_id":1}` |
| `GET /{block_id}` | 查询块内图片、审核进度和操作历史 |
| `POST /{block_id}/release` | 本人交回或管理员回收，提交 `expected_revision` 与可选 `reason` |
| `GET /assignees` | 管理员查询可分配的启用账号 |
| `POST /{block_id}/assign` | 管理员转交，提交 `expected_revision`、`user_id` 与可选 `reason` |
| `POST /{block_id}/reopen` | 管理员重新打开完成块，提交 `expected_revision` 与必填 `reason` |

上述 `expected_revision` 使用最新块详情中的 `revision`，发生冲突时刷新后重试。确认无目标使用 `POST /api/assets/{asset_id}/workflow`，请求为 `{"action":"confirm_empty","expected_revision":图片当前版本号}`；空白图片未经确认不能直接提交。

## 标注工作流

左侧导航按项目工作流排列，桌面可收起为图标，手机使用菜单抽屉。进入训练后，左侧保留可筛选、分页的训练记录，右侧顶部切换“训练概况”“参数与日志”“模型转换”；AI 标注页切换任务配置与任务历史。页内标签按账号和项目记忆，切换模块时保留已有的未保存编辑保护。

1. 管理员创建项目，选择检测、分割、分类或关键点并定义类别。关键点项目同时定义有序点名、骨架和可选的左右翻转映射（默认人体 17 点）。
2. 上传图片、文件夹或 ZIP。图片分批上传、校验并按内容去重。
3. 进入“AI 标注中心”，点击“配置与预览效果”，选择模型、提示词、最低置信度和处理范围。在右侧选择 1–3 张有代表性的图片，点击“预览效果”；可反复调参试标，满意后按当前参数启动正式标注。默认处理未标注图片，也可按选图或全部图片批量运行。模型未配置时会显示原因，不会生成演示结果。任务历史中每条记录提供“提交审核”：任务结束后自动使用该任务确实保存过结果的图片范围，预览当前保存的标注（包括人工校正）后再提交；失败或取消任务可提交已保存部分，排队或运行期间需等待结束。
4. 标注员进入“标注与审核”检查 AI 结果，也可跳过 AI，直接从空白图片开始手动标注。画布左侧提供带文字的矩形框、多边形、关键点工具，顶部保留类别选择；分类项目直接选择图片类别即可保存。关键点先框选对象，再按项目点序定位，支持跳过、回退以及可见/遮挡/未标注状态。使用选择工具可拖动对象和控制点。人工修改保留原始模型来源并标为“已校正”，后续 AI 替换会保留这些对象。
5. 在数据页选择图片，或在“AI 标注”点击“批量提交与审核”；“标注与审核”顶部的“更多”中也提供批量入口，可在当前页面批量提交、通过或退回（每次最多 500 张）。选图面板支持文件名搜索、状态筛选、全选筛选结果和清空选择。先预览可处理与跳过项，批量通过还需确认已检查结果，退回原因可选。执行时再次核对每张图片版本、编辑锁及 AI 任务；成功项移出选择，冲突项保留并说明原因。通过和退回只处理待审核状态，不会把 AI 草稿直接通过。未完成或尚未保存的画布修改需先处理，再打开批量操作。单图通过或退回成功后，自动进入当前范围内的下一张待审核图片；任务块内审核不会跳到其他块。当前范围没有可继续审核的图片时，块内审核返回任务块列表，项目审核返回数据页的待审核列表；其他成员正在处理的图片会跳过并给出提示。有退回图片的块仍处于需修改状态，只有全部图片通过后才算完成。待审核及已通过图片默认不会被 AI 改写。
6. 审核员或管理员从通过的数据生成不可变版本。向导依次选择数据、划分比例、配置增强、预览确认。在一条三段比例条上拖动两个分界手柄，调整训练、验证、测试比例，合计保持 100%；也可输入精确百分比，实时显示预计张数；随机种子可保持默认。配置增强时，选择方法、修改参数或切换图片后会自动显示原图与增强图对照，以及同步变换的标注；支持鼠标、触控和键盘操作。最后确认后才生成。版本列表显示保存时的缩略图和增强设置，点击“查看版本图片”可按分组浏览和分页。
7. 从版本导出 YOLO、COCO 或完整 JSON；分类项目提供分类目录 ZIP 与 JSON，关键点导出保留点序、可见性和骨架。
8. 选择与版本兼容的本地权重，提交后台训练。在训练页面左侧选择记录，右侧查看当前训练的进度、训练与验证 loss、不同损失分量、验证表现和逐轮数值；每完成一轮自动刷新。完成后下载 `best.pt`，或点击“转换并导出”选择 ONNX、TorchScript、RKNN、TensorRT，完成后下载模型及部署说明。

单图审核快捷键：`Y` 通过当前图片，`X` 打开退回窗口；退回窗口的原因可以留空，确认后继续审核。单图和批量退回都支持不填写原因；填写的文字会保存在审核记录中。快捷键仅在“标注与审核”页面、图片为待审核状态且当前账号有审核权限时生效；输入框内输入、弹窗打开、有未保存草稿或请求处理中不会触发审核，避免误操作。版本冲突或提交失败时保留当前图片，刷新后重新检查。

项目总览显示累计训练、进行中、完成和失败的次数，以及最近 3 次训练的详情入口。训练记录每页 10 条，支持名称或模型搜索、状态和任务类型筛选；翻页不会切换右侧详情，可用“清除筛选并定位”回到当前记录。所选训练保存在链接 `#/projects/{id}/train?run={run_id}` 中，同一账号与项目的搜索、筛选、页码在当前浏览器会话内保留。窄屏可展开“切换训练”，选择后收起列表。后台刷新保留正在查看的曲线、展开项、表单和滚动位置。活动训练约每 3 秒同步状态；没有活动任务时仍每 15 秒检查其他成员的新训练，切回页面或恢复联网会立即同步。列表和详情独立更新，曲线、日志、转换记录与环境检查不会阻塞状态显示；连接失败时保留上次结果并明确提示自动重连。状态轮询使用 `include_availability=false` 跳过耗时的模型转换环境探测。

AI 任务历史每页显示 8 条，支持模型名或任务编号搜索及状态筛选，每条历史保留“提交审核”入口。数据版本每页显示 6 个，支持名称、编号或说明搜索，缩略图、图片浏览、下载和训练入口均随记录保留。列表显示总数、筛选结果数和当前页，无匹配时可一键清除筛选。

版本创建后没有更新接口。导出和训练只读取版本自己的 SQLite 快照及媒体副本，后续重新打开、修改或删除活动标注不会改变已有版本。 缩略图和原图预览同样读取版本媒体副本；生成比例是目标比例，实际图片按整数分配。小样本无法分出验证图片时会提示，仍可保存版本下载，但暂不能用于平台训练。

训练曲线只使用实际保存的轮次，不补造缺失值；旧记录中的无名 loss 分量保留为“未命名分量”。新训练保存训练器提供的分量名称，最终最佳模型评估与末轮指标分开保存，避免覆盖曲线。检测、分割、关键点分别显示对应的框、掩膜、关键点评分，分类显示准确率。mAP 和准确率的曲线纵轴固定在 0–1，loss 从 0 起按实际数值自适应；越界比例或无效数值显示为缺失，不会伪装成有效结果。恢复任务时仅保留与 checkpoint 对应的历史前缀；没有可恢复 checkpoint 的重启会清理旧曲线。

按任务提交审核使用服务端逐图处理记录，不会使用项目中其他已选图片。已提交、已通过、无有效标注、编辑占用和新 AI 任务占用会分别反馈；超过 500 张的任务分批预览与确认。重试 AI 任务会使旧审核预览失效，需重新打开任务结果。缺少逐图结果清单的早期历史任务会说明无法确定范围，可改用“跨任务选择与审核”手动选图。

数据页每张图片提供“删除图片”，勾选后也可“删除所选”（仅管理员，每批最多 500 张）。确认窗口显示待删除图片、当前标注对象数及不能删除的原因。删除会移除当前图片、当前标注与逐图审核记录，保留项目审计、历史数据版本及训练记录；已删除图片可以重新导入。占用中的图片和排队或运行中的 AI 任务图片不能删除，其他图片仍可独立处理。失败后需重新预览剩余项，再确认删除。当前界面没有回收站；原文件清理异常会记录在删除审计中供管理员处理。

训练后端默认读取：

```dotenv
MDP_TRAINING_ENABLED=true
MDP_TRAINING_BASE_MODEL=./models/training/yolo26n.pt
MDP_TRAINING_SEGMENTATION_MODEL=./models/training/yolo26n-seg.pt
MDP_TRAINING_MODEL_DIRS=./models/training:./models
```

`MDP_TRAINING_MODEL_DIRS` 只应指向管理员管理的可信 checkpoint 目录；平台仅扫描其一级 `*.pt` 文件，并读取 checkpoint 的真实 task，而不是根据文件名猜测。Compose 使用 `MDP_TRAINING_MODEL_HOST_DIR` 将一个目录只读挂载到 `/training-models`。

`GET /api/training/catalog` 返回模型 SHA-256、参数量、真实任务、默认配置、可训练性和禁用原因；`GET /api/training/resources` 返回 CPU/GPU、队列和 pipeline worker 状态。`GET /api/projects/{id}/training-runs` 返回运行、资源选择、谱系与产物信息。缺少依赖或兼容权重时不会排入一个必然失败的占位任务。TensorRT engine 需要 CUDA 和 `tensorrt` Python 运行时。

训练列表传入 `page` 时在数据库分页，`page_size` 默认 10、最大 50，支持 `q`、`status`、`task` 筛选及 `locate_id` 定位；`pagination.total` 为筛选后的数量，顶层 `total` 和 `counts` 始终为项目全部记录的统计。不传 `page` 保持原有列表接口兼容。`GET /api/projects/{id}/training-summary` 为总览提供轻量统计及最近记录，不扫描模型或读取产物文件。

四类任务的数据约定：

- `detect`：矩形框。旧混合项目的多边形可显式转换为外接框训练。
- `segment`：实例多边形。矩形转换成四角轮廓时会显示精度退化提示。
- `classify`：每张图片恰有一个类别；训练使用类别文件夹，并在 checkpoint 恢复原始类别名。暂不支持多标签分类。
- `pose`：每个对象有一个框和固定顺序的关键点；可见性为 `0` 未标注、`1` 遮挡、`2` 可见。所有类别共用项目的关键点定义。没有 `flip_idx` 时禁用训练水平翻转。

分类和关键点需要在可信模型目录提供对应任务的 `.pt` 权重（通常为 `*-cls.pt`、`*-pose.pt`），或接入相应远程 AI 服务。训练目录检查 checkpoint 的实际任务；本地 AI 适配器按常用文件名注册，推理时再次验证真实任务。固定类别模型的类别名称需与项目一致，关键点数量及顺序也必须匹配。OBB 仍不支持。小数据集请检查划分，训练集和验证集均需有图片，分类训练集还应覆盖所有类别。

训练创建时会冻结数据版本哈希、基础权重 SHA-256、后端版本、任务适配和全部允许参数。Worker 使用 execution generation 做 fencing，每次失联恢复写入独立 `attempt-*` 目录；存在 `last.pt` 时继续既有 epoch，checkpoint 保留训练状态时一并恢复优化器/调度器，已被上游剥离时则从其权重继续并记录降级事件。训练与转换都提供持久日志、取消、显式重试谱系以及带 SHA-256/大小的产物元数据。

### 数据版本增强

首次可保持“不增强”生成基准版本，之后逐步选择与实际场景相符的变化。生成方式参考 [Roboflow 的版本增强流程](https://docs.roboflow.com/datasets/versions/dataset-versions/image-augmentation)：先划分原图，再为训练图片生成副本，原图保留，验证集和测试集保持原样。

| 增强方式 | 可调整内容 | 使用提示 |
|---|---|---|
| 水平翻转 | 应用概率 | 镜像图片与标注；关键点必须先配置左右点映射 |
| 垂直翻转 | 应用概率 | 适合无固定上下方向的场景，例如俯视零件 |
| 直角旋转 | 90° / 180° / 270°、应用概率 | 随机选择已勾选角度，同步改变宽高与几何标注 |
| 亮度、对比度、饱和度 | 系数上下限、应用概率 | 默认 0.8–1.2，1 表示不变；颜色决定类别时谨慎改变饱和度 |
| 灰度 | 应用概率 | 去掉颜色信息，不适合依赖颜色分类的任务 |
| 模糊 | 半径 0.1–5、应用概率 | 模拟失焦，小目标先查看效果 |
| 噪声 | 强度 1–30、应用概率 | 模拟传感器颗粒，避免覆盖细节 |
| 伽马变化 | 伽马上下限 0.2–3、应用概率 | 模拟不同曝光响应；1 不变，大于 1 变暗，小于 1 变亮 |
| 色相偏移 | 偏移上下限 −0.5–0.5、应用概率 | 数值表示色相环的一圈比例；颜色决定类别时不建议使用 |
| 锐度变化 | 系数上下限 0–3、应用概率 | 1 不变，小于 1 柔化，大于 1 锐化；过强会出现边缘伪影 |
| 自动对比度 | 截断比例 0–10%、应用概率 | 拉伸明暗范围；高截断比例可能丢失亮部、暗部细节 |
| 直方图均衡 | 应用概率 | 增强明暗分布差异；可能改变自然色彩和局部对比度 |
| JPEG 压缩 | 质量上下限 10–100、应用概率 | 模拟压缩块与细节损失；数值越低压缩失真越明显 |
| 低分辨率模拟 | 缩小比例上下限 0.1–1、应用概率 | 先缩小再还原原尺寸，模拟分辨率不足；标注位置不变 |

扩增量可以按训练集倍数（包含训练原图）或新增张数设置。例如 100 张训练原图扩增到 3 倍，计划新增 200 张；验证集和测试集仍保持原数量。新增配额按随机种子稳定分配到训练原图，每张最多新增 20 份。所选方法按顺序组合，每种方法按配置概率独立应用。向导显示最多新增和最终总量；没有变化或与该原图其他副本相同的像素与标注组合会跳过，因此实际张数可能低于目标，版本记录实际新增及跳过数量。生成上限为新增 5000 张、总计 20000 张、新增图片总像素 20 亿。旧版每张固定副本数的配置和历史版本继续兼容。

增强配置步骤自动预览，连续调参会短暂防抖，并合并为最新设置，避免重复计算。配置页使用统一的主体滚动，桌面并列显示参数与效果，手机提供查看效果入口，底部数量说明和高级参数均可滚动查看。预览使用同一变换算法，只尝试所选图片计划中的前 3 份增强副本，可更换预览图片；未分配新增配额的图片会说明原因，自动选择会优先展示有配额的训练图片。相同原图、参数和随机种子可重复得到相同效果。确认页会重新核对数据；预览数量明确显示为“预计最多”，重复或未变化的副本可能被跳过。预览后若图片、标注或类别发生变化，提交会提示重新预览。版本保存增强配置、每张副本的来源及实际参数，导出和训练使用这些已冻结文件。训练器仍有默认在线增强，选择增强版本训练时会提示叠加效果，建议与基准版本对比。

带旋转或镜像 EXIF 方向的旧图片可能与既有标注坐标不一致，预览和增强会明确拒绝。请先将图片实际转正、清除方向信息，重新导入并确认标注后再生成。

### 模型转换

四种格式始终显示；缺少转换环境时显示原因并禁止提交。转换任务使用独立进程，支持取消、按原参数重试、查看日志和 SHA-256 校验下载，不修改训练权重。输入边长需为 32 的倍数。检测、实例分割、分类和关键点均走对应任务的导出流程；模型能否在目标设备执行仍取决于芯片支持的算子、内存和运行时。

| 格式 | 适用环境 | 主要配置 |
|---|---|---|
| ONNX | ONNX Runtime 等通用推理环境 | 输入尺寸、FP16、动态输入、图简化 |
| TorchScript | PyTorch / LibTorch | 输入尺寸、FP16 |
| RKNN | Rockchip NPU | 目标芯片、浮点 / INT8、校准图片数量、均值与标准差、量化算法、优化等级 |
| TensorRT `.engine` | NVIDIA CUDA GPU | FP32 / FP16、批大小、动态输入、构建工作区上限、GPU |

RKNN 当前支持 RK3588、RK3576、RK3566、RK3568、RK3562、RV1103、RV1106 和 RV1126B。RV1103 / RV1106 仅允许 INT8；RV1126B 与旧 RV1126 不是同一目标。转换固定为单张 RGB、静态尺寸，先导出不含 NMS 的 ONNX，再使用 Toolkit2 构建。默认均值 `0,0,0`、标准差 `255,255,255` 与当前 YOLO 训练的 0–1 归一化一致；修改时界面会提示其影响。

INT8 校准只读取这次训练使用的冻结版本中的 **训练集**。可调整图片数量，系统确定性抽样并验证文件哈希，按任务执行 letterbox（填充 114）或分类中心裁剪。不会使用验证集、测试集或后来修改的活动图片；校准清单和实际数量会写入部署说明。少于请求数量、文件缺失或哈希不一致时会明确失败。

RKNN Toolkit2 与训练环境的 ONNX / NumPy 依赖不同，建议使用独立环境：

```bash
python3.10 -m venv .venv-rknn
.venv-rknn/bin/python -m pip install -r requirements-conversion-rknn.txt
# 在 .env 填写该解释器的绝对路径，然后重启 Web 和 pipeline worker。
# MDP_RKNN_PYTHON=/absolute/path/to/.venv-rknn/bin/python
```

留空 `MDP_RKNN_PYTHON` 时使用服务自身的 Python。平台检测 SDK 是否实际可导入及版本是否至少为 2.3.2；转换主机无需连接 Rockchip 板卡。容器部署时，该路径必须位于 Web 与 pipeline 容器内部，可在自定义镜像中创建独立环境；主机虚拟环境路径不能直接作为容器路径。

TensorRT 安装到 Web 与训练 worker 共用的 Python 环境；使用独立镜像时，两者都需具备该依赖，以便检测环境及执行转换：

```bash
.venv/bin/python -m pip install -r requirements-conversion-tensorrt.txt
```

此依赖文件固定 TensorRT 10.13.3.9 的 CUDA 12 包，需按 NVIDIA 的[版本支持说明](https://docs.nvidia.com/deeplearning/tensorrt/10.x.x/getting-started/release-notes-10/10.13.3.html)核对目标机器的驱动和运行时。构建时申请 GPU 资源租约；INT8 TensorRT 尚未开放，避免没有校准时生成误导性结果。动态输入的实际 min / opt / max profile 会记录到部署说明。动态 ONNX / TensorRT 关闭模型内固定数量的端到端筛选，避免较小尺寸的候选框不足导致执行失败；检测、分割和关键点模型因此需要部署端执行置信度筛选与 NMS。固定尺寸导出保留原模型行为，具体以后处理说明为准。

完成后可分别下载模型与 `manifest.json`，包含标签顺序、关键点定义、输入预处理、输出结构、工具版本、来源哈希及目标硬件信息。RKNN 保留常规 Ultralytics 输出，并非 Rockchip Model Zoo 的多分支优化模型，不能直接套用其专用后处理；部署端需查询实际张量类型和量化参数。TensorRT 文件含 Ultralytics 元数据头，说明中记录跳过头部的偏移，也可以直接用 Ultralytics 加载。引擎通常需要在目标 GPU 和兼容运行时重新构建，参见 [TensorRT 支持矩阵](https://docs.nvidia.com/deeplearning/tensorrt/10.x.x/getting-started/support-matrix.html)。编译成功不代表已在目标板验证推理精度。

API：`GET /api/training-runs/{id}/conversion-options` 返回格式可用性、参数默认值和校准图片数量；`POST /api/training-runs/{id}/conversions` 创建转换，RKNN 使用 `format: "rknn"` 与嵌套 `rknn` 配置，TensorRT 使用 `format: "engine"`；`GET /api/conversions/{id}/artifact` 下载模型，`GET /api/conversions/{id}/manifest` 下载部署说明。早期转换没有说明文件时界面不显示该下载按钮。

隔离转换检查（随机初始化的未训练模型，只验证转换流程，不评估准确率）：

```bash
.venv/bin/python scripts/smoke_conversions.py --formats rknn --tasks detect segment classify pose --quantized
CUDA_VISIBLE_DEVICES=0 .venv/bin/python scripts/smoke_conversions.py --formats engine --device cuda:0
```

Ultralytics 官方默认许可为 AGPL-3.0，并提供 Enterprise License。生产分发或闭源商业部署前，部署方必须按自身场景确认许可；平台会展示提示，但不会自动完成许可证合规。

兼容旧工作流的项目级快速 YOLO 导出也会按内容哈希稳定划分 80% train / 20% val（数据不足时保证两个集合不重叠）。项目中一旦包含多边形，全部对象统一输出 YOLO Segment 格式，矩形会转换成四角多边形；生产训练仍建议优先从不可变版本导出。

审核通过或已提交的数据默认不会被人工或 AI 任务覆盖，必须先重新打开。AI 任务仅锁定它的目标图片，其他图片仍可由成员处理；重复任务和重试也遵守同一互斥规则。失联任务可恢复或取消，自动重领不会重复写入已完成图片。

Grounding DINO 是按类别文本查询的开放词汇检测器，不会理解“尽量完整”这类指令。
其目标类别建议使用简短英文名，例如 `person`、`helmet`、`car`，并以逗号分隔。
SAM3 同样建议使用简短英文概念。Qwen 等视觉语言模型的任务说明仍可使用中文自然语言。
SAM2 使用当前选中的项目标签保存分割结果。

## 内置本地标注模型

平台启动时自动注册以下本地模型，并在“模型服务”页面显示权重健康状态：

| 模型 | 模式 | 本地目录 | 作用 |
|---|---|---|---|
| Grounding DINO Tiny | 全自动 | `models/grounding-dino-tiny` | 按项目类别查找全部目标并生成矩形框 |
| SAM 3 | 全自动 | `MDP_SAM3_CHECKPOINT` | 按文本概念查找全部实例并生成多边形轮廓 |
| SAM 2.1 Hiera Tiny | 半自动 | `models/sam2.1-hiera-tiny` | 根据正负点或粗框生成多边形轮廓 |

可自动下载模型的来源、固定版本和许可证见
[模型下载清单](../model-catalog/models.json)。本地推理使用已下载的权重，不会在处理业务图片时联网下载。

标注页使用紧凑的顶部操作区、左侧绘制工具和底部缩放栏。普通说明不占用画布，未完成草稿、只读与保存失败提示会明确显示。点击“专注标注”可收起导航及两侧面板；退出后恢复原来的面板布局。侧栏和专注模式切换不重建画布，未完成的轮廓、关键点及高级输入会保留。

AI 效果预览支持检测框、分割轮廓、整图分类和关键点骨架，显示类别、置信度与过滤情况；可切换样本、放大查看或隐藏预测对照原图。预览调用实际模型，但不创建任务、标注、类别或编辑锁，也不改变审核状态。修改模型、提示词、阈值或样本后，旧结果会明确标为过期；关闭窗口后的迟到响应不会更新新窗口。正式批量标注复用当前参数，仍遵循人工标注保护和审核规则。

Grounding DINO 与 SAM 3 使用目标类别文本，管理员可在预览中尝试新类别，只有启动正式标注时才添加到项目。视觉语言模型接受自然语言要求；本地 YOLO 的类别由训练权重决定，提示词不用于扩展其类别。最低置信度同时参与支持此参数的本地模型候选生成与最终结果筛选；降低阈值可能增加召回和误检。无置信度的模型结果会显示人工检查提示。

预览接口：`POST /api/projects/{id}/annotation-preview`，请求字段与创建标注任务一致，但 `asset_ids` 必须包含 1–3 个不同的图片 ID，交互辅助模式限 1 张。返回逐图预测、过滤计数和待新增类别，不持久化结果。模型忙碌、超时与失败会返回明确状态；预览与批量任务共用参数校验和预测筛选逻辑。

## 快捷键

在“标注与审核”点击画布左侧“快捷键”或按 `?`，可查看当前任务适用的按键和项目类别数字键。手动标注不依赖 AI 模型。

| 快捷键 | 功能 |
|---|---|
| `V` | 选择对象 |
| `R` | 绘制矩形框 |
| `P` | 绘制多边形 |
| `K` | 创建关键点对象：先拖框，再逐点定位 |
| `Enter` | 完成多边形或关键点；保存失败后重试当前草稿 |
| `Backspace` / `Ctrl+Z`（Mac 为 `⌘Z`） | 撤销草稿中的最后一个轮廓顶点或关键点 |
| `Esc` | 取消当前绘制或定位；没有草稿时取消对象选中，保留已保存标注 |
| `Delete` / `Backspace`（`⌫`） | 无绘制草稿时，删除选中的已保存对象；分类任务清除图片类别 |
| `A` / `←`、`D` / `→` | 上一张、下一张 |
| `N` | 当前筛选内的下一张待校正图片 |
| 类别旁的数字键 | 明确选中对象时修改该对象类别；其余时候选择新对象类别；分类任务直接保存 |
| `H` 或按住空格拖动 | 平移画布 |
| 滚轮、`+` / `-` | 缩放图片 |
| `F` | 适配窗口 |
| `Ctrl+C` / `Ctrl+V`（Mac 为 `⌘C` / `⌘V`） | 复制、粘贴对象，仅限同一项目 |
| `?` | 查看快捷键帮助 |
| 右键 / 点击对象的类别标签 | 选择已有对象；右键可改类别、调整边界、复制或删除 |

矩形工具在鼠标悬停图片时显示贯穿图片的横纵辅助线；拖框时显示实际像素宽高，缩放不会改变读数含义。关键点的框选阶段同样提供辅助线。移动图片、保存或只读状态下自动隐藏。

选择工具下可直接拖动对象整体；选中后拖动白色控制点可调整矩形四角、四边中点或多边形顶点。选中对象的控制点始终位于最上层，避免被重叠对象遮挡；单击时的小幅鼠标抖动不会保存成位置修改。

无需退出绘制工具，就能右键已有对象修改类别。多个对象重叠时，菜单提供目标对象选择；“移动 / 调整边界”进入选择工具，“继续绘制”恢复原来的矩形、多边形或关键点工具。也可点击画布上的类别标签或侧栏对象列表，在右侧标注详情中改类别；数字键仅在明确选中对象后修改该对象类别。顶部“新对象类别”用于接下来新建的标注，画完后仍可连续绘制。触屏用户可通过右侧对象列表与“更多”按钮使用同样功能。选中对象后只在画布高亮轮廓与控制点，不再显示遮挡图片的浮动操作栏；无草稿时按 `Esc` 可取消选中。

删除标注：按 `V` 选择对象或点击其类别标签，再按键盘 `Delete` 或 `Backspace`（`⌫`）删除。绘制多边形或关键点时，`Backspace` 仍只撤销最后一个点。顶部工具栏不显示删除按钮；右键菜单和侧栏保留删除入口。只删除当前标注，原图片保留；分类任务在画布中按 `Delete` 或 `Backspace`（`⌫`）可清除已保存的类别，也可通过侧栏“清除类别”操作。未选中对象、存在未完成修改或图片不可编辑时不能删除；输入框中按删除键只编辑输入内容，删除失败会保留画面并提示重新加载核对。

多边形也可通过点击起点、双击或 Enter 完成，右键可撤销最后一个顶点。

完成绘制、选定分类或修改对象后自动保存。新建标注、对象类别、分类和关键点修改保存失败时会保留本地草稿，并提供“重试保存”和“重新加载已保存结果”；类别修改只提交新类别，不会同时提交高级编辑区中未应用的坐标或属性。多人同时修改发生版本冲突时不会覆盖另一人的新结果，应重新加载核对。未完成草稿会阻止切图、切模块及退出登录，刷新或关闭页面时由浏览器提醒；草稿尚未持久化到本地，离开前应确认“已保存”。

快捷键仅在标注页面生效，输入文字、选择表单、中文输入法组合输入和对话框内不会触发绘制或删除。浏览器常用组合键保持原行为；按住按键不会重复提交、删除或切图。只读图片仍可平移、缩放和切图。

## 远程视觉模型协议

平台向检测、分割、分类或关键点服务发送：

```json
{
  "image_base64": "...",
  "prompt": "找出所有人员和安全帽",
  "labels": ["person", "helmet"],
  "hints": {
    "points": [
      {"x": 220, "y": 160, "label": 1},
      {"x": 310, "y": 190, "label": 0}
    ]
  },
  "config": {}
}
```

框/多边形提示会使用 `shape_type`、扁平 `points` 和 `label`。分割、分类和关键点项目的 `hints.task_type` 分别为 `segment`、`classify`、`pose`；关键点请求还包含 `hints.keypoint_schema`（有序 `names`、`skeleton`、`flip_idx`）。旧混合项目无任务提示时保持原协议。

分类对象返回 `{"label":"cat","shape_type":"classification","confidence":0.9}`；关键点对象返回 `{"label":"person","bbox":[10,10,80,80],"keypoints":[[20,20,2],[40,40,1]],"confidence":0.9}`，点数与项目定义一致。坐标可为绝对像素或在响应中声明 `normalized_1000`。

服务返回：

```json
{
  "coordinate_space": "absolute",
  "objects": [
    {
      "label": "person",
      "bbox": [118, 77, 384, 465],
      "confidence": 0.96,
      "attributes": {"occluded": false}
    },
    {
      "label": "helmet",
      "polygon": [210, 90, 260, 86, 281, 125, 224, 138],
      "confidence": 0.91,
      "attributes": {}
    }
  ]
}
```

`coordinate_space` 支持 `absolute`、`normalized_1000` 和 `normalized_1`。平台会丢弃未知类别、非有限/越界/零面积坐标、低置信度结果以及不符合标签属性 Schema 的结果。推理客户端不继承系统 `HTTP_PROXY`，避免内部图像数据被环境代理转发。

## 生产边界

当前生产边界是单机或单节点私有化落地：SQLite WAL、共享本地持久卷、一个 Web 和一个合并标注/训练/转换的计算服务。训练任务使用租约、执行代次 fencing、独立 attempt 目录与单机 GPU 独占资源锁，进程失联后可安全重领；pipeline 状态可从健康接口和资源接口观察。

跨主机高可用仍需要 PostgreSQL、S3/MinIO、分布式调度/事件队列、企业 SSO、多租户 RBAC、集中式指标告警和备份恢复演练。不要把 SQLite 数据卷或训练 attempt 目录放在不保证锁语义与原子 rename 的网络文件系统上，也不要把“单节点可恢复”描述成跨节点高可用。

生产配置、就绪监控、上传限额、依赖审查及尚未消除的风险见 [生产部署与上线审查](production.md)。
